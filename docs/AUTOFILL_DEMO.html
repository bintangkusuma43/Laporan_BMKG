🚀 Autofill Petugas - Bidirectional

Fitur autofill dua arah antara Nama dan NIP dengan datalist HTML5. Implementasi production-ready dengan validasi dan sync state tracking.

✅ Dua Arah Nama ↔ NIP
🔍 Search Di kedua field
🛡️ Validasi Sinkronisasi otomatis
⚡ No Loop Sync state tracking

📋 Demo Interaktif

Contoh 1 Single Row Autofill

Coba ketik nama atau NIP di salah satu field. Field pasangan akan terisi otomatis saat Anda selesai input.

Petugas Pelaksana

Contoh 2 Multiple Rows (Form Laporan)

Setiap baris memiliki autofill yang independent dengan datalist terpisah.

💡 Tip: Coba ketik "ARDH" atau "1981" untuk melihat suggestions dengan datalist HTML5 native.

📝 Cara Implementasi

1 Script Include

Tambahkan script petugasAutofill.js ke HTML Anda:

<script src="/laporan_bmkg/assets/js/petugasAutofill.js"></script>

2 HTML Input

Buat input dengan class nama dan nip, serta list attribute:

<input type="text" class="nama" id="nama_petugas" list="list_nama" autocomplete="off" /> <input type="text" class="nip" id="nip_petugas" list="list_nip" autocomplete="off" />

3 Bind JavaScript

Bind kedua input dengan PetugasAutofill.bindRow():

const namaInput = document.querySelector('.nama'); const nipInput = document.querySelector('.nip'); PetugasAutofill.bindRow(namaInput, nipInput, { onSelect: ({nama, nip}) => { console.log('Selected:', nama, nip); } });

4 Selesai!

Autofill siap digunakan dengan datalist dropdown dan validasi bidirectional.
